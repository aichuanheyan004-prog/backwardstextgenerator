Privacy

Privacy Policy

Backwards Text Generator is designed as a browser-local text utility. This policy describes what the site itself does and does not collect. Last updated: July 28, 2026.

Text you type or paste

The conversion runs in your browser with JavaScript. This site does not send your text to an application server, database, analytics service, or model API. Your input and output are not made public by this site.

Clipboard

The Copy button asks your browser to write the generated output to your clipboard. Clipboard access happens only after you press Copy. If permission is unavailable, the tool selects the output so you can copy it manually.

PNG export

Exact visual modes create the PNG in your browser with a temporary canvas and object URL. The site does not upload the image or text, and the temporary object URL is revoked after the download starts.

Accounts, cookies, and analytics

Version one of this site has no accounts, comments, advertising scripts, analytics tags, or cookie banner because it does not set analytics or marketing cookies.

Hosting logs

The hosting provider may process standard request data such as IP address, requested URL, user agent, timestamp, and error logs to deliver and protect the site. Those logs are controlled by the hosting provider and are not designed to include the text you type into the tool.

Changes

If analytics, contact forms, ads, accounts, or server-side text processing are added later, this policy should be updated before those features go live.
